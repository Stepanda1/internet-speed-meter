# Internet Speed Meter

Тестовое задание: Python-скрипт принимает URL файла, выполняет **10 последовательных запросов**, полностью скачивает каждый ответ и выводит среднее время запроса, суммарный объём данных и скорость в **Мбит/с**.

## Запуск

Нужен Python 3.10 или новее. Используется только стандартная библиотека, устанавливать зависимости не требуется.

```bash
git clone https://github.com/Stepanda1/internet-speed-meter.git
cd internet-speed-meter
python speed_meter.py "https://speed.cloudflare.com/__down?bytes=1000000"
```

В Windows можно использовать `py` вместо `python`, в Linux/macOS – `python3`.
Пример выше запрашивает файл размером 1 MB и расходует примерно 10 MB трафика за полный запуск. Можно передать прямую ссылку на тяжёлую картинку или другой файл:

```bash
python speed_meter.py "https://example.com/large-image.jpg" --timeout 60
```

`example.com/large-image.jpg` – шаблон, замените его реальной ссылкой. URL с `&` и другими специальными символами заключайте в кавычки. `--timeout` задаёт максимальное ожидание отдельной операции сокета, а не общий лимит времени всего запуска. По умолчанию это 30 секунд.

## Расчёт

Для каждого запроса измеряется время от начала открытия соединения до полного чтения тела ответа. Следующий запрос начинается только после завершения предыдущего. Данные читаются блоками по 64 KiB и не сохраняются на диск. Объём считается по реально прочитанным байтам тела ответа, без HTTP-заголовков и сетевых накладных расходов.

```text
среднее время = сумма времени 10 запросов / 10
скорость, Мбит/с = суммарные байты × 8 / суммарное время / 1 000 000
```

Итоговая скорость учитывает время всех запросов. Арифметическое среднее десяти отдельных скоростей не используется. 1 MB = 1 000 000 байт; Мбит/с и MB/с отличаются в 8 раз.

Скрипт просит сервер не использовать кэш и сжатие; выполнение этих заголовков зависит от сервера. Стандартные HTTP-перенаправления обрабатываются автоматически. При HTTP-ошибке, таймауте, пустом или неполном ответе выполнение прекращается с кодом 1, итоговая скорость не выводится. Некорректные аргументы дают код 2, Ctrl+C – 130.

Это измерение скорости скачивания с выбранного сервера с учётом задержек соединения. Результат зависит от сервера, размера файла, VPN и нагрузки на сеть и не гарантирует измерения предельной скорости подключения. На маленьком файле задержка соединения может заметно занижать результат.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Тесты запускают локальный HTTP-сервер и проверяют реальное скачивание, ровно 10 последовательных запросов, учёт байтов, формулу скорости, ошибки HTTP, неполный и пустой ответ, таймауты и валидацию аргументов. Доступ к интернету для тестов не нужен.
